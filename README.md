## An Intelligent Driver Monitoring System for Drowsiness and Distraction Detection

The DriveGuard is a web-based Driver Monitoring System designed to detect driver drowsiness and distraction in real time using computer vision and webcam-based analysis.

The system analyzes facial landmarks, eye movements, mouth movements, and head pose to identify possible signs of drowsiness and reduced driver attention. It also provides real-time alerts and session-based monitoring information.
